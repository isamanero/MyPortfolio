# 🌍 Procesamiento de Imágenes Satelitales (LST)

Este repositorio contiene los materiales necesarios para replicar el cálculo de **Land Surface Temperature (LST)** utilizando imágenes satelitales en QGIS.

---

## 📂 Contenido del repositorio

📄 **PDF de instrucciones**  
Guía paso a paso para descargar, preparar y procesar la imagen satelital.

🧠 **Script de PyQGIS**  
Script listo para ejecutar en la consola de Python de :contentReference[oaicite:0]{index=0}.

🎥 **Vídeo de ejecución (≈40s)**  
Demostración rápida del funcionamiento del script dentro de QGIS.

---

## 🛰️ Fuente de datos

Las imágenes utilizadas se obtienen de Earthexplores y OSM.

---

## 🚀 Uso del repositorio

1. Abrir el PDF de instrucciones  
2. Descargar y preparar la imagen satelital (BANDA 10) a usar siguiendo las instrucciones
3. Cargar el script en QGIS  
4. Ejecutar el script  
5. Visualizar el resultado (mapa LST)
